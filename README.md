# 🦞 钓龙虾

一个基于 Phaser 3 的钓鱼小游戏：站在岸边钓小龙虾，把虾拖出水面后丢进岸边水桶里才算捕获成功。

## 玩法

1. **放饵**：点击水桶旁的**饵料盒**可查看/更换饵料（点击短暂显示剩余量），把钓竿伸到水面上方，点击放饵，饵料沉到水底
2. **等虾咬钩**：饵沉底后吸引小龙虾爬过来（饵越好吸引范围越大）；水面出现红色警示圈、线晃动时，**点击收杆**
3. **拖出水面**：收杆把虾拉出水面，挂在竿尖下方
4. **丢进桶里**：移动钓竿让虾对准岸边水桶（桶会发光），**点击投放**，虾进桶才计分
5. **查看统计**：点击岸边**水桶**查看当前捕获数量（按 7 种龙虾分类）

> 注意：虾放进桶里才算捕获成功；只拖出水面不算。

- 按数量计分：每钓到一只 `+1`（不分大小）
- **饵料系统**：5 种饵料（小田螺 / 大田螺 / 小青蛙 / 大青蛙 / 猪肝）放在水桶旁的**饵料盒**里，点击盒子换下一种饵并短暂显示剩余量；每次放饵损耗 1 点耐久，咬钩时按虾大小额外损耗（**大虾吃得快**，消耗较慢）
- **饵料用光**：不弹提示（模拟现实）——钩上不再显示有饵、龙虾也不再上钩；看到钩上没饵就是信号，点击饵料盒换上新的
- **吸引差异**：大田螺、大青蛙、猪肝吸引半径更大，甚至可以同时吸引**两只**龙虾同时上钩
- **荷叶**：水面飘着荷叶，收杆时虾穿过荷叶大概率会被碰掉回水里，注意避开
- **鱼线长度**：**滚轮是唯一控制**——上滚放长、下滚缩短（范围 `LINE_MIN`~`LINE_MAX`），**点击不再收线/放线**；线缩短到默认长度以下时，多余部分**缠在竹竿上**显示，可缩到很短（最短 30）；线太短饵够不到水底就不会吸引/咬钩，放长线才能钓
- **握竿拖拽**：**按住竿身任意位置**（命中即握在该处）拖动——竿指向鼠标方位（绝对指向），人物同时随鼠标横向走位（拖动一次完成走位+瞄准）；松手后竿保持当前角度，指针完全空闲；悬停竿上光标变抓手，无任何文字提示
- **键盘**：`←`/`→`（或 `A`/`D`）控制人物沿岸边前后移动；**`F` 捡起/放下钓竿**——放下时竿落在地面（收回鱼线、释放挂钩的虾、不再响应钓鱼操作），**必须走到地上的钓竿旁边才能按 `F` 捡起**（无任何提示文字）
- **换饵**：饵还在水里时点饵料盒只看剩余；用滚轮把饵缩出水面即可换饵；钩上饵被吃光后点饵料盒会直接补上新饵
- 咬钩后太久不收杆，虾会挣脱逃跑
- 收杆越快、离水面越近，虾越容易挣脱；拖出水面后举得越高也越容易挣脱（**连点可加速收杆**，但更冒险）
- 水底泥岸上有龙虾洞，小龙虾会钻进去躲藏，过一会儿再钻出来（挣脱的虾会沉回水底再爬回洞里）
- 水里有 7 种龙虾：红龙虾、老龙虾、单钳龙虾、青龙虾、带籽母龙虾、黑龙虾、软皮龙虾——体色、钳数、卵簇、软壳各不相同，爬行速度也有差异
- 有日夜循环：太阳/月亮位置与亮度跟随**真实时钟**（白天太阳东升西落，夜晚月亮星星升起、画面变暗）；太阳月亮在背景层，不会遮挡人物
- 没有关卡限制，可以一直钓下去，看看能钓多少分

## 运行

基于 Phaser 3，无构建步骤，直接用浏览器打开即可：

```bash
# 方式一：直接打开
open index.html

# 方式二：本地静态服务器（推荐，体验更稳定）
python3 -m http.server 8000
# 然后访问 http://localhost:8000
```

支持鼠标和触屏（手机浏览器可直接玩，建议横屏）。

**移动端适配**：
- 竖屏时自动显示「请旋转手机」提示（触屏设备）
- 触摸手势由 Phaser 接管：页面不滚动、不缩放、无长按菜单
- **线长控制**：触屏设备右侧显示竖向**线长滑块**（上=放长 下=缩短），桌面仍用鼠标滚轮
- 右上角 ⛶ 全屏按钮（iOS Safari 不支持元素全屏时自动隐藏）
- 适配刘海屏安全区（`env(safe-area-inset-*)`）

## 项目结构

```
crayfishing/
├── index.html      # 页面骨架：画布、饵料提示、水桶面板、脚本加载顺序
├── css/
│   └── style.css   # 页面样式
└── js/
    ├── config.js   # 配置数据（布局/物种/饵料/荷叶/饵料盒等，全部集中在这里）
    ├── state.js    # 共享状态对象 Game + 工具（单一数据源，模块间通过它读写）
    ├── effects.js  # 特效：气泡/水花/特效更新
    ├── crays.js    # 龙虾系统：生成/贴地移动/洞/坠落/挣脱/荷叶/捕获
    ├── bait.js     # 饵料系统：耐久/吸引/咬钩/用光/饵料盒
    ├── phases.js   # 钓竿物理 + 鱼线状态机 + 挣脱概率
    ├── input.js    # 指针与点击交互（由 Phaser 桥接坐标）
    ├── ui.js       # 水桶统计面板/饵料剩余提示（Mustache 模板渲染）
    ├── sprites.js  # 素材库：所有角色与场景的绘制（实体用 Twemoji 精灵，场景程序化）
    ├── assets.js   # 素材管理：Twemoji 加载 + 按龙虾种类染色预渲染
    ├── scene.js    # Phaser 场景：预加载素材、驱动逻辑、画布纹理桥接渲染、输入绑定
    ├── game.js     # 入口：Phaser 配置启动、startGame、调试钩子
    └── vendor/
        ├── phaser.min.js     # Phaser 3.87（MIT），游戏引擎
        └── mustache.min.js   # Mustache.js v4.2.0（MIT），UI 模板解析渲染
assets/               # 素材图片（Twemoji，CC-BY 4.0，见 CREDITS.md）
└── crayfish/frog/snail/bucket/meat/hook.png
```

> ⚠️ 脚本加载顺序有依赖（`config` → `state` → 系统模块 → Phaser → `input`/`ui` → `sprites` → `scene` → `game`），在 `index.html` 中已按序引入，改动时不要打乱。

## 技术要点

- **基于 Phaser 3**（`js/vendor/phaser.min.js`，MIT）：Phaser 负责游戏循环、输入、等比缩放（FIT）与相机效果；UI 模板用内联的 Mustache.js（`js/vendor/mustache.min.js`）
- **实体精灵**：龙虾（按种类染色）、水桶、饵料（青蛙/田螺/猪肝）使用 **Twemoji** 素材（`assets/`，CC-BY 4.0，见 `CREDITS.md`），加载失败时回退程序化绘制
- **画布纹理桥接渲染**：`js/scene.js` 把 `sprites.js` 的绘制（精灵 + 程序化场景）画进 Phaser CanvasTexture，每帧刷新显示
- **全局配置**：所有尺寸集中在 `CFG`（`js/config.js`），改一处即可调整整个场景
- **绘制与逻辑分离**：`sprites.js` 只负责画，逻辑按模块拆分（见项目结构）
- **调试钩子**：浏览器控制台可通过 `__game` 查看内部状态（当前阶段、分数、虾位置等）

## 难度

游戏无关卡限制，无限畅玩。小龙虾数量与爬行速度在 `js/config.js` 的 `CRAY_COUNT` / `CRAY_SPEED` 中调整；龙虾洞位置在 `CFG.HOLES` 中调整。
